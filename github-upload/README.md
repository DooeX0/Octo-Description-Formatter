# Octo Description Formatter

Веб-инструмент для подготовки описаний аккаунтов к массовому импорту в Octo Browser.

## Возможности

- Загрузка XLSX, CSV и TXT, выбор листа и столбца с данными.
- Разделение данных аккаунта на строки по выбранному разделителю.
- Настройка почты, пароля, резервной почты, телефона, SMS-ссылки и дополнительного кода.
- Добавление почты в имя профиля: `51US-DO|email@example.com`.
- Поиск по имени профиля и описанию.
- Выделение всего описания одним кликом.
- Экспорт в CSV и оформленный XLSX с заголовками и подсказками шаблона Octo.
- История файлов и восстановление открытого файла, настроек и поиска после обновления страницы.

Файлы обрабатываются в браузере. История хранится в IndexedDB на устройстве пользователя.

## Локальный запуск

Откройте `index.html` в современном браузере. Установка зависимостей и сборка не требуются.
Для чтения и записи XLSX используется библиотека `xlsx-js-style` версии `1.2.0`, загружаемая с jsDelivr.

## Публикация на GitHub Pages

1. В репозитории выберите **Add file → Upload files**.
2. Загрузите файлы из этого проекта прямо в корень репозитория. `index.html` и `favicon.svg` должны лежать рядом, без вложенной папки `xlsx`.
3. Подтвердите загрузку через **Commit changes**.
4. Откройте **Settings → Pages**.
5. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем **Save**.
6. После завершения публикации откройте адрес сайта, показанный в настройках Pages.

Для репозитория `DooeX0/Octo-Description-Formatter` стандартный адрес будет:

`https://dooex0.github.io/Octo-Description-Formatter/`

[Инструкция GitHub по настройке Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Файлы проекта

- `index.html` — интерфейс, стили и логика приложения.
- `favicon.svg` — значок вкладки браузера.
- `.nojekyll` — публикация готового статического сайта без обработки Jekyll.
- `.gitignore` — исключения для локальных файлов и выгрузок.

Поиск фильтрует предпросмотр. Экспорт содержит все обработанные аккаунты.
